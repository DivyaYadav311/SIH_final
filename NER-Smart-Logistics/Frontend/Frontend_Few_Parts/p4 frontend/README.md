# P5 Frontend Test UI

This frontend is deliberately dependency-free so it can be removed after integration.

## Run
1. Start the P5 API on port 8000.
2. From this folder run a static server, e.g.:

```bash
python -m http.server 5500
```

3. Open `http://localhost:5500`.

If your backend runs elsewhere, change `API` in `src/app.js`.
